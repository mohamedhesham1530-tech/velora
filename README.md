# Velora — Premium E-Commerce Flutter Application

A modern Flutter e-commerce application built with a scalable feature-based architecture and a focus on clean UI, smooth user experience, and reliable application flow.

## Features

- User authentication
- Product browsing and categories
- Search and filtering
- Product details
- Shopping cart
- Wishlist
- Checkout
- Shipping addresses
- Order management
- Notifications
- User profile
- Arabic / English localization
- RTL / LTR support
- Light / Dark mode
- Responsive UI
- Modern Material 3 design

## Tech Stack

- Flutter
- Dart
- BLoC / Cubit
- Firebase Authentication
- REST APIs
- Dio
- SharedPreferences
- Dependency Injection
- Material 3

## Architecture

The application follows a feature-based architecture designed to keep the codebase organized, scalable, and maintainable.

Each major application feature is separated into its own module while shared functionality is handled through reusable core components.
